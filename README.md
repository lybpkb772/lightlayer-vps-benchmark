## 美国 VPS 测评到底测什么：四个数决定一台机器值不值

不用把 bench 脚本的每一项都跑完，抓住四个可核验的数就够了。

**第一，晚高峰的三网延迟。** 美国西海岸到国内的正常水位是：电信 150–180ms，联通 160–200ms，移动 170–210ms。超过 300ms 基本可以判定回程绕了普通国际线路。测试时间点很重要，白天测得漂亮、晚上 8 点到 11 点崩掉的机器很常见，两个时段各测一次才有意义。

**第二，晚高峰丢包率。** 1% 以内算优秀，5% 以内能用，超过 10% 就别犹豫了。丢包比延迟更能毁掉体验，200ms 但零丢包的机器，用起来比 150ms 但丢包 8% 的机器顺手得多。

**第三，回程线路走哪家。** 实际使用中大部分流量走的是回程方向，网页加载、文件下载、API 响应都靠回程，所以回程直连对体验的影响远大于去程。测法是 SSH 里跑 `besttrace` 或 `backtrace`，看回程有没有走 59.43 段（电信 CN2）、219.158 段（联通 9929）或者 CMIN2，然后再用 itdog、ping.pe 交叉看一眼去程。去程绕路、回程直连的组合，比反过来要强。

**第四，实测下载速度。** 这一项最容易被误读，下面单独说。

关于带宽有个常见误判：标 1000Mbps 的机器，国内下载只跑到 10MB/s，就有人喊虚标。跨境传输受国际出口带宽限制，本地跑不满标称值是常态。公开测评里，美西优化线路机器的国内单线程下载普遍落在 6–12MB/s 这个区间，晚高峰还会往下掉一档。标称带宽真正起作用的地方是机房本地传输和多线程并发，余量足不足，看你跑什么业务。

还有一条要提前建立预期：**线路好不等于 IP 干净**。公开测评里出现过三网回程走 CN2 GIA、但 Netflix 和 Disney+ 检测结果都是 No 的机器。优化线路解决的是速度，解锁是另一件事，两件事得分开测。

## 三个容易踩的坑：端口、升级方向、双 ISP

### 默认所有端口是关的

机器开通后，防火墙默认阻止全部端口。SSH 连不上、网站打不开，不是机器坏了，是要先去面板的防火墙设置里，把你要用的端口逐个加进去放行。这一步新手最容易卡住，卡住了会以为买到了坏机器。

### 不限流量和限流量的升级方向不一样

不限流量的套餐只能升带宽，不能加流量（本来就没有流量上限）；限流量的套餐只能加流量，不能升带宽。买之前想清楚自己未来半年是"流量会爆"还是"带宽不够"，选错组，后面只能换套餐不能原地升级。

面板里内存、CPU、硬盘、IP、快照都可以按需单独加，主机也能 PUSH 给其他账户。这些是加分项，但改不了上面那条硬规则。

### 双 ISP 不等于住宅 IP

搜美国 VPS 的时候你会反复看到"双 ISP""原生 IP""住宅 IP"三个词，行业里混用得厉害，得掰开。

原生 IP 指的是 IP 注册地和使用地在同一个国家，没被转卖过。双 ISP 指的是这个 IP 同时挂在两个运营商的属性下。**机房里的双 ISP，本质上仍然是机房 IP**，归属和机房一致；住宅 IP 走的是当地家庭宽带线路，在平台风控眼里的权重更高。有测评作者专门做过这个切割，原话是"注意是机房双 ISP，不是家宽住宅 IP"。

所以看到"双 ISP"就当"纯净度比普通机房 IP 好一点的机房 IP"来理解，别当成住宅 IP 用。做跨境电商、社媒养号这类对 IP 属性要求严格的业务，先买一台单机实测，别一上来批量上。LightLayer 的公开资料里没有主打双 ISP 或住宅 IP 卖点，如果你在别处看到这类宣传，回到官方页面看它对 IP 属性的原始定义。
